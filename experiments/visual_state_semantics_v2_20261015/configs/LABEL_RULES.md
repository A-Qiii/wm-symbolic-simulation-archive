# 新版状态定义与边界（采集前冻结协议的中文说明）

这版将旧七事实扩展为九事实：三个 Holding、三个 In，以及 Closed、Open、Intermediate。旧标签和旧评分不覆盖；所有真实新帧同时保存旧标签与新版标签。新版本不再把 NOT Open 解释为 Closed。

|事实／条件|操作性定义|边界与原因|
|---|---|---|
|Closed(drawer)|抽屉原生关节开度 q≤0.020 m|与固定执行器关严要求一致；q距0.020 m在±0.003 m内时，三种抽屉标签均不计作确定监督|
|Open(drawer)|q≥0.180 m|与固定执行器打开完成要求一致；距0.180 m在±0.003 m内也保留不确定|
|Intermediate(drawer)|0.020<q<0.180 m|真正的第三种状态；不是误报、不是Closed；边界区仍单独标为不可确定|
|Holding(object)|固定执行器原有双指家族承重接触、没有外部物体支撑|保持既有定义用于迁移对照，不用夹爪闭合替代抓持|
|In(object,drawer)|真实物块八个角点完整位于抽屉内腔、存在向上承重支撑链通向抽屉、未Held；链上可移动支撑物也必须完整位于内腔|既不是质心在抽屉上方，也不是任意接触抽屉。堆叠突出边沿的上层物块为false，即便支撑归属于抽屉|
|几何包含|使用原生URDF物块尺寸×0.8、当前真实旋转及原生抽屉link坐标变换；内腔局部坐标x[-.18,.18]、y[.02,.08]、z[-.04,.16]米|抽屉局部y是竖直维；A/C与B抽屉世界位置不同，不能复制D世界坐标|
|侧壁／边沿容差|所有侧壁和上边沿最小有符号余量≥2mm才确定在内；≤−2mm确定在外；中间条带不确定|避免把接近边界的数值误差当作稳定视觉标签；底面只允许最多3mm仿真穿透容差|
|承重支撑边|接触力>0.01N、作用于被支撑物体的世界向上法向z>0.5、接触间距≤3mm|排除侧擦、向下接触、外侧接触和没有通向抽屉的物块循环|
|接触不确定|可能影响支撑的力在0.005–0.015N或向上法向在0.45–0.55之间|几何明确在外或Held时In仍确定false；几何在内但支撑靠临界接触时不强行给确定标签|

所有接触、物块位姿、抽屉link变换、关节位置只存_private，用于监督和独立评分。视觉输入仍只有双相机RGB与本体状态。模型有独立的三种抽屉查询，三种输出联合softmax且互斥，不从Open取反得到Closed。不会把GT的Closed/In结果送给视觉执行端。

所有配置在configs/protocol.json、labels_v2.py的SPEC与collection_frozen.json中有采集前哈希。边界例被保留：评估同时报告有效掩码覆盖，不把不确定例隐藏成正确。遇到本来想构造“边缘接触”但物块真实落下或滑入的情况，记录实际物理类别，不能按预期条件硬贴标签。

27个根组：A/B共18组用于训练，C共9组用于开发；同根各复位条件成对比较，不当独立根。每组固定8种场景条件或一条4技能链。旧312窗口只可复用Holding监督，无法证明新In/Closed标签的旧样本不会被硬迁移。模型训练只有一次固定seed、1200更新和预先指定的开发选择规则。新D验收只有在协议中的审计、类别覆盖、误报率和开发正确率条件通过后才考虑。

关闭容量／摆放诊断：同根、同物块、同抽屉开度，分别以真实复位构造并排与堆叠，使用完全相同的固定Close执行器。记录力、接触对象、位姿及失败原因；不增大推力、不改碰撞、不把复位伪称为动作。堆叠阻塞而并排成功只能支持“摆放造成限制”的判断；还需逐帧接触证据，不能仅凭一帧猜定原因。

## A首批审计后的v2.1实现说明

采集的首16个回合仅来自A。若存在一条各边力≥0.015N、向上法向≥0.55的完整内含支撑路径，其他平行弱接触不应把它改为不确定；v2.1修正了该掩码实现并去重相同支撑路径。原v2窗口和物理trace不覆盖，由独立重算targets_v2_1供训练，全部差异单独保存。首批尝试的外侧反例在稳定窗口前滑落，保留原尝试，额外添加outside_front_supported复位分支。v2.1在任何C数据或训练结果之前冻结。总回合上限171，技能调用上限仍108，三种语义和容差不放宽。
